# Aman Roney — Frontend Web Developer Portfolio

A high-performance personal portfolio showcasing frontend web development, modern UI engineering, responsive web design, and interactive experiences.

## 🚀 Overview

This portfolio is a modern React-based web application built with a focus on immersive user experiences (UX) and cinematic aesthetics. It features advanced scroll animations, interactive components, and clean design.

### Key Features
- **Frontend Stack**: React, JavaScript (ES6+), Tailwind CSS, HTML5, CSS3.
- **Immersive Interactivity**: Fluid animations and interactive UI components.
- **Scroll-Driven Design**: Custom scroll stacks for showcasing selected projects.
- **Responsive Architecture**: Fully optimized for mobile, tablet, and desktop viewports.
- **Tactile UX**: Smooth scrolling powered by Lenis and Framer Motion.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### Local Development

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```
